# Session 1 - Task 2: Machine Learning Scenario Classification

## Task Overview
Given the following scenarios, classify each as supervised, unsupervised, or reinforcement learning with a one-line explanation for each choice:
1. Netflix recommending movies based on your watch history
2. Spotify grouping similar songs into playlists
3. A self-driving car learning to park by trial and error

---

## Classifications & One-Line Explanations

| # | Scenario | ML Classification | One-Line Explanation |
|---|---|---|---|
| **1** | **Netflix movie recommendations based on watch history** | **Supervised Learning** | It predicts user ratings/watch probabilities by learning mapping functions from historical user watch history (features) to known user interaction outcomes (labels). |
| **2** | **Spotify grouping similar songs into playlists** | **Unsupervised Learning** | It groups songs into clusters based on audio feature embeddings (danceability, tempo, acousticness) without using predefined categories or ground-truth labels. |
| **3** | **Self-driving car learning to park by trial and error** | **Reinforcement Learning** | An autonomous agent learns an optimal parking policy by taking actions in a dynamic environment and optimizing behavior based on feedback rewards and collision penalties. |
