# Session 1: Fundamentals of Machine Learning

This folder contains code scripts and markdown write-ups for all tasks in **Session 1**.

## Directory Structure
- [`task_1/`](task_1/): Everyday apps (Zomato, Instagram, Flipkart) & ML paradigm analysis (Supervised, Unsupervised, RL).
- [`task_2/`](task_2/): Scenario classification (Netflix, Spotify, Self-driving car) with one-line justifications.
- [`task_3/`](task_3/): Basic ML Workflow diagram (`ml_workflow_swiggy.png`) with Swiggy food delivery ETA step examples.
- [`task_4/`](task_4/): WhatsApp spam filter analysis comparing Traditional Programming vs Machine Learning.

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_1/task_1/task_1.py
python session_1/task_2/task_2.py
python session_1/task_3/task_3.py
python session_1/task_4/task_4.py
```
