# Session 16: Classification Evaluation Metrics

This folder contains Python scripts, mathematical breakdowns, and detailed markdown write-ups for all tasks in **Session 16: Classification Model Evaluation Metrics (Confusion Matrix, Precision, Recall, F1-Score, and ROC-AUC)**.

## Directory Structure
- [`task_1/`](task_1/): Manual mathematical calculation of Confusion Matrix metrics (Accuracy, Precision, Recall, F1) for a Spam Filter system.
- [`task_2/`](task_2/): Custom reusable `print_confusion_matrix` Python function formatting and metric summary generator.
- [`task_3/`](task_3/): Precision vs Recall trade-off analysis for a Fake News Detection algorithm on social media.
- [`task_4/`](task_4/): F1-Score computation and trade-off evaluation for a Food Delivery Fraud Detection system.
- [`task_5/`](task_5/): ROC Curve generation and Area Under Curve (AUC) evaluation with optimal threshold selection via Youden's J statistic.

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_16/task_1/task_1.py
python session_16/task_2/task_2.py
python session_16/task_3/task_3.py
python session_16/task_4/task_4.py
python session_16/task_5/task_5.py
```
