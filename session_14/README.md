# Session 14: Support Vector Machines (SVM) & Kernel Methods

This folder contains Python scripts, visualization figures, and detailed markdown write-ups for all tasks in **Session 14**.

## Directory Structure
- [`task_1/`](task_1/): Music genre linear SVM classifier (`Pop` vs `Classical`) with decision boundary visualization (`svm_music_boundary.png`).
- [`task_2/`](task_2/): Flipkart product review sentiment classifier using `SVC(kernel='linear')` and `CountVectorizer`.
- [`task_3/`](task_3/): IPL player performance kernel benchmark comparing **Polynomial ($d=3$)** vs **RBF (Gaussian)** kernels.
- [`task_4/`](task_4/): Zomato restaurant rating SVM with explicit visualization of the decision boundary, margin lines ($2/\|\mathbf{w}\|$), and support vectors (`zomato_svm_margin.png`).

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_14/task_1/task_1.py
python session_14/task_2/task_2.py
python session_14/task_3/task_3.py
python session_14/task_4/task_4.py
```
