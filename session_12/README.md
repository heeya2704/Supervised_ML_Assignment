# Session 12: Decision Tree Classifiers & Tree Pruning

This folder contains Python scripts, visualization figures, and detailed markdown write-ups for all tasks in **Session 12**.

## Directory Structure
- [`task_1/`](task_1/): Full-depth `DecisionTreeClassifier` on Iris dataset with tree structure visualization (`iris_decision_tree.png`).
- [`task_2/`](task_2/): Splitting criterion benchmark comparing **Gini Impurity** vs **Entropy (Information Gain)**.
- [`task_3/`](task_3/): Pre-pruned tree structure (`max_depth=2`) with structural change analysis (`iris_tree_maxdepth2.png`).
- [`task_4/`](task_4/): Feature importance score extraction, ranking, and Gini decrease analysis on Iris features.
- [`task_5/`](task_5/): Swiggy food delivery speed classifier (`swiggy_tree.png`) with step-by-step interpretation of the top 3 node splits.

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_12/task_1/task_1.py
python session_12/task_2/task_2.py
python session_12/task_3/task_3.py
python session_12/task_4/task_4.py
python session_12/task_5/task_5.py
```
