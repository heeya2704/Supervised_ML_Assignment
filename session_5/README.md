# Session 5: Simple Linear Regression & Prediction Analysis

This folder contains data generation scripts, linear model implementations, visualization plots, and markdown reports for all tasks in **Session 5**.

## Directory Structure
- [`task_1/`](task_1/): Data generation for Instagram usage vs battery % & scatter plot (`scatter_plot.png`).
- [`task_2/`](task_2/): Fitting `LinearRegression` model, extracting slope ($m = -12.04$), intercept ($b = 105.42$), and interpretation.
- [`task_3/`](task_3/): Predicting end-of-day battery percentage for new usage scenarios ($3.0$, $4.5$, and $7.0$ hours).
- [`task_4/`](task_4/): Evaluation metrics calculation (MAE $= 1.29\%$, RMSE $= 1.58\%$, $R^2 = 0.9933$).
- [`task_5/`](task_5/): Visualization of best-fit regression line with scatter data (`regression_line.png`).

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_5/task_1/task_1.py
python session_5/task_2/task_2.py
python session_5/task_3/task_3.py
python session_5/task_4/task_4.py
python session_5/task_5/task_5.py
```
