# Session 2: Model Evaluation, Data Splitting & Bias-Variance Tradeoff

This folder contains dataset scripts, code files, graphs, and markdown summaries for all tasks in **Session 2**.

## Directory Structure
- [`dataset/`](dataset/): Contains `spotify_top_50.csv` dataset.
- [`task_1/`](task_1/): Loading dataset, feature selection vs label identification.
- [`task_2/`](task_2/): Splitting dataset into 80% train and 20% test using `train_test_split`.
- [`task_3/`](task_3/): Extreme 5% train / 95% test split linear regression experiment & performance analysis.
- [`task_4/`](task_4/): Bias-Variance Tradeoff graph (`bias_variance_tradeoff.png`) and Zomato app analysis.
- [`task_5/`](task_5/): Real-world overfitting example in daily apps (Instagram Reels recommendation engine).

## How to Run Python Scripts
```bash
python session_2/task_1/task_1.py
python session_2/task_2/task_2.py
python session_2/task_3/task_3.py
python session_2/task_4/task_4.py
python session_2/task_5/task_5.py
```
