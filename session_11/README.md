# Session 11: K-Nearest Neighbors (KNN) & Naive Bayes Classifiers

This folder contains Python scripts, dataset generators, and detailed markdown write-ups for all tasks in **Session 11**.

## Directory Structure
- [`task_1/`](task_1/): Flipkart review sentiment classifier using `CountVectorizer` and `KNeighborsClassifier`.
- [`task_2/`](task_2/): Spotify playlist track classifier comparing **Euclidean distance ($L_2$)** vs **Manhattan distance ($L_1$)** metrics.
- [`task_3/`](task_3/): IRCTC train booking status predictor using `GaussianNB`.
- [`task_4/`](task_4/): WhatsApp message classifier (`personal`, `group`, `spam`) using `MultinomialNB` with confusion matrix visualization.
- [`task_5/`](task_5/): AI-generated KNN image classifier distinguishing between cricket bats and footballs (8x8 pixel vectors) with error fix notes.

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_11/task_1/task_1.py
python session_11/task_2/task_2.py
python session_11/task_3/task_3.py
python session_11/task_4/task_4.py
python session_11/task_5/task_5.py
```
