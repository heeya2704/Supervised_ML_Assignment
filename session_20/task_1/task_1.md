# Session 20 - Task 1: Time Series Visualization of Daily Temperature Data

## Task Overview
Load daily temperature data for Ahmedabad, plot raw observations using `matplotlib`, and visually identify trend and seasonal patterns.

---

## Visualization
The raw temperature plot is saved to [`raw_temperature_plot.png`](raw_temperature_plot.png).

---

## Visual Pattern Identification

- **Annual Seasonality**: Strong repeating annual cycle with peak summer temperatures reaching ~38°C–42°C (May–June) and winter minimums dropping to ~16°C–20°C (January).
- **Long-Term Trend**: A subtle positive linear trend across the 2-year observation window.
- **Short-Term Fluctuations (Noise)**: Day-to-day weather variation superimposed on the annual sinusoidal cycle.
