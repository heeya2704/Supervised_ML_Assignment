# Session 15: Boosting Algorithms (Gradient Boosting & AdaBoost)

This folder contains Python scripts and detailed markdown write-ups for all tasks in **Session 15**.

## Directory Structure
- [`task_1/`](task_1/): Default `GradientBoostingClassifier` trained on Iris flower dataset (**93.33% accuracy**).
- [`task_2/`](task_2/): `AdaBoostClassifier` using decision stumps on Flipkart product reviews with complete classification report.
- [`task_3/`](task_3/): Theoretical analysis of Weak vs Strong Learners with real-world app examples (Instagram, Paytm).
- [`task_4/`](task_4/): Hyperparameter tuning benchmark for `n_estimators` and `learning_rate` in Gradient Boosting (**97.78% peak accuracy**).
- [`task_5/`](task_5/): Real-world case study on Boosting applied to Paytm's real-time payment fraud detection engine.

## How to Run Python Scripts
Run individual task scripts from the workspace root:
```bash
python session_15/task_1/task_1.py
python session_15/task_2/task_2.py
python session_15/task_3/task_3.py
python session_15/task_4/task_4.py
python session_15/task_5/task_5.py
```
